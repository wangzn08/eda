# V167：完整位移范围响应曲线的可行性检查

## 为什么换表示

V164 使用有限理想图的长暂态和九锚点响应后，验证分达到 99.2451；扩大到 V166 的 1023 叶子 / 1024 树，初步为 99.2478，容量收益有限。V164 的困难请求仍集中：最高失分的 5% 请求占总失分约 58%，障碍通道请求低于直接路径。

V167 尝试把不稳定的周期外推替换为完整的离散响应曲线。参考 Nowak & Charron-Bost (2014) 的暂态/最终周期区分，但不能直接用其矩阵幂定理证明位移模型已稳定。曲线本身来自架构理想图 Dijkstra，不读取验证标签。

## 采样定义

- 源核心编号 0、53、106、159；每个源覆盖 160 个终点核心。
- 横向位移 -119 至 119。
- 纵向正负两个方向，各 12 个余数、48 个周期，覆盖绝对位移 0 至 575。纵向零点会重复，便于统一索引。
- 理想图搜索窗口 x±156、y±624；非负边成本，Dial 距离桶上限 9000。所有采样点必须被访问；越界路径仍不在搜索内，因此结果是有限理想图最短路，不是无限图或真实 FPGA 的全局正确性证明。
- 每条曲线减去原始核心基点成本和方向周期基准，再分离首点偏置；对剩余 48 个整数值做无损字典共享和 XZ。

首批原始响应约 352.4MB。若生成全部 160 个源，原始响应约 14.1GB；必须先检查无损压缩，不能把这个原始尺寸当作提交文件。四源压缩结果的40倍只是可行性参考，不保证全量压缩比例。

## 决策顺序

1. 执行四源生成，测量曲线数量、唯一规范化曲线数量和无损压缩字节数。
2. 完整解码逐值一致，检查后段斜率变化比例。
3. 若尺寸有空间，再制作独立候选，重算终点/源分支选择，评估完整验证；不把旧模型下的候选提示直接当作新响应的正确选择。
4. 只有精度有明显改善才实现压缩原生加载与同版串行测速。失败则记录原因，保留 V158。

可能的后续存储方向：仅保留曲线重建所需的低纵向基点切片，替换旧近区/横纵方向资产，以减少重复；终点胜者也可能用曲线变化点表达。这些是尚未实施、未计入当前成绩的设计。
