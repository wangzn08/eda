# P4 第三项实验：架构 Gap/Block 特征

## 假设与方法

第二项位移表对特殊区域没有位置感知。按照官方 `SRB_Gap.json`，本实验为每条请求提取端点包围盒跨过的 19 条 Line 和相交的 7 个 Block 的指示特征。Block 指示只代表包围盒相交，并不声称最短路径真正穿过 Block。相应残差系数仅在固定开发集上拟合，使用阻尼与正则化；独立验证集仅用于比较。沿用位移桶宽 8/16，最终留出集未使用。

| 指标 | 原位移表 | 加 Gap/Block 特征 |
|---|---:|---:|
| 正延时评分 | 85.17 | **86.89** |
| 相对误差 P50 | 2.48% | **2.07%** |
| 相对误差 P95 | 12.77% | **11.68%** |
| 相对误差 P99 | 24.91% | **23.69%** |
| 短距离（曼哈顿距离≤20）评分，1881条 | 49.25 | **50.76** |
| 端点包围盒与Block相交，71815条 | 87.71 | **89.57** |

两种正则强度（100、1000）结果接近，上表采用 1000。特征只有 26 项，理论上适合固化为常量表，但尚未测 C++ 单线程吞吐和内存。整体分数增加约 1.72，短距离表现仍差；不能据此认为方案满足提交条件。开发/验证样本分别为 700705/150053 条；训练及评估 Python 总耗时约 32.6 秒，不是推理吞吐。

## 决策

保留该特征校正作为高速候选。下一步针对近距离请求做局部精确搜索或更细的局部位移表，避免远距离模型的截距主导小延时；然后再将固定模型导出到 C++ 并测端到端速度。原精确搜索仍为正确性参照。复跑命令：`python3 scripts/experiment_gap_features.py`；[详细数值](P4-gap-features.json)。
