# 新架构探索整轮：V99–V102

## 问题与实验约束

目标是同一实现尽量达到99.9验证分和单线程十亿请求一小时预算。V93保留版本99.1667786，既有微优化不能证明达到共同目标。跨障碍与不跨障碍各承担约一半评分损失，不能只继续调整绕障碍项。

本轮按用户要求积累一整轮改动，不逐个微实验提交 Git。训练只读取 development 700705 条；完整 validation 150053 条用于比较；未读取 holdout。重复使用验证集进行选择意味着分数可能乐观。百万测速关闭缓存、真实CSV输出，交错顺序各两次，分别报告初始化与请求CPU时间；不运行完整十亿重复输入。

## 方法和创新边界

1. **物理边界增强的对称树（V99）**：在71个原有特征上增加52个端点边界特征，包含芯片边缘、障碍左右侧、100行相位以及2/4/8/16局部尺度截断距离。替换旧校正头，不叠加两套头。此为物理表征改进，不是全新搜索算法。
2. **六维 TT 残差（V99/V101）**：维度为源端口、目标端口、有向水平相位、有向垂直相位、水平距离段、垂直距离段，秩8/16。连乘表达跨维耦合。第一次对已训练模型残差拟合，第二次直接对无学习头的架构模板拟合，并改用平滑绝对误差、延长固定训练轮数。不能将第一次近零修正直接当成证明TT表达能力不足。
3. **多尺度联合哈希与小网络（V99/V101）**：四个离散尺度1/4/16/64，各65536桶、4维向量，32宽网络消歧，约4.2MB参数。它不同于V70的加法标量桶，但没有原论文的空间多线性插值。当前两轮均没有改善，不能宣称论文方法在本题必然无效。
4. **非对称边界树（V100）**：使用LightGBM叶子优先结构、端点边界与端口/相位/距离联合编码，比较31/127叶、64/128/256/512棵。新C++数值内核直接读取紧凑节点二进制，保留double阈值和叶值。训练时不调用路径搜索。
5. **零误差门控与正负专家（V102）**：先判断近零、低估、高估三种误差区间，再由独立条件专家修正。动机是开发集原始模板57.20%误差为0，中位误差为0，少数大误差值得局部修正。该比例是开发集逐条相同的比例，不是验证评分。

TT、哈希编码、梯度提升、门控专家均为已有基础方法。本项目创新候选是FPGA周期相位、实际边界、端口耦合和稀疏误差修正的组合，尚没有学术首创或99.9的证据。

## 参考文献与复现

- [Si 等，An efficient tensor regression for high-dimensional data](https://arxiv.org/abs/2205.13734)：参考TT连乘与秩/层次结构。原文采用正交结构和黎曼优化，本轮Adam与加权损失不继承其理论保证。
- [Yin 等，TT-Rec (MLSys 2021)](https://arxiv.org/abs/2101.11714)：参考存储、秩、执行代价的共同权衡及乘积初始化。推荐系统/加速器结论不能直接用于本题CPU。
- [Müller 等，Instant Neural Graphics Primitives with a Multiresolution Hash Encoding (SIGGRAPH 2022)](https://arxiv.org/abs/2201.05989)：参考多尺度学习编码、小网络消歧；本轮不是CUDA或网格插值复现。
- [CatBoost (NeurIPS 2018)](https://proceedings.neurips.cc/paper/2018/hash/14491b756b3a51daac41c24863285549-Abstract.html)：对称残差树基线。
- [LightGBM (NeurIPS 2017)](https://proceedings.neurips.cc/paper/2017/hash/6449f44a102fde848669bdd9eb6b76fa-Abstract.html)：非对称树对照。

前三篇PDF及作者HTML已下载到papers，阅读相关方法、初始化、实现和局限章节；目录说明见papers/README.md。

脚本：

- `scripts/experiment_architecture_round.py`：V99固定训练与完整验证。
- `scripts/experiment_asymmetric_boundary.py`：V100非对称树。
- `scripts/experiment_raw_structured_residual.py`：V101排除学习基线依赖的对照。
- `scripts/experiment_gated_residual.py`：V102稀疏误差门控。
- `scripts/benchmark_boundary_round.py`：C++输出核对及同一二进制配对测速。
- `scripts/export_asymmetric_boundary.py`：无LightGBM运行依赖的数值树导出。

最终分数、文件预算、差异和CPU证据以本目录对应JSON为准。1ps舍入差异必须报告，不能写成完全一致；最终比较采用C++实际输出评分。未提供官方Linux验收、隐藏分布或完整十亿实测结论。

## 下一轮要改变什么

本轮开发诊断表明物理模板57.20%请求原本完全正确；完整验证旧64的最大误差10%请求承担73.90%评分损失。因此只修复非常少量的请求不足以达到99.9，需要同时改善较广的系统性误差。

优先探索**带真实代价的路径见证编译**，而不是再扩大同一全局残差头：

1. 从架构图生成端点邻域、长线接续和局部回绕的合法路径片段，同时保存经过的坐标与Gap/Block事件；每段的代价直接按照实际架构计价。
2. 用周期片段/重复循环的压缩表示，把长路线表示为入口、周期段、出口；显式区分边缘不可用、额外跨线、跨障碍带的情况。路径与min-plus连接是文献已有方法，组合方式和压缩数据布局才是项目候选贡献。
3. 对照“只估算标量距离”与“重建合法路径后计价”，先在固定开发派生样本检查非法路径率与系统偏差，再比较完整validation；不读取holdout。
4. 宏路径V65–V69及小型专家V51–V54已经失败。下一轮必须改变局部片段和真实代价表示，不能只换beam宽度或增加专家数量。固定实验预算，记录失败机制；有完整精度改善才移植C++并用配对吞吐测量筛选。

该方向尚未实现，不将其写成已获得的创新或成绩。V40仍保留为高精度但过慢的参考，V93仍为此前速度参考，本轮边界64为小幅精度改进候选，非对称与门控作为新架构研究资产保留。全部本轮进程已结束；未创建微实验Git提交。
