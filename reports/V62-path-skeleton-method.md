# V62：真实路径重复结构探查

参考 Botea、Harabor，Path Planning with Compressed All-Pairs Shortest Paths Data，ICAPS 2013（papers/README.md 收录作者公开稿）。借鉴路径数据压缩的方向，本实验尚未实现论文的压缩最短路径数据库。

从原有按距离分层的开发集600条中每25条取1条，共24条。CompactSolver::trace 执行真实架构图上的精确搜索，导出每个到达端口、位置和路径次序。24条延时全部匹配对应开发集参考答案。没有使用保留集。

分析连续转移中的长度1至4的精确重复模式。签名包含起终端口及真实坐标位移，所以跨障碍产生的位移变化不会被误合并。312个转移压为183个模式内转移记录，减少41.35%。这个数字没有计入重复次数和索引元数据，不代表实际文件压缩率；小样本也不代表整个架构。

下一步实现候选路径表示：入口连接段、可重复的闭合端口循环、出口连接段，并保留实际位置上的障碍检查。必须先证明连接连续、循环回到同一端口及总延时正确，再评估小候选库的覆盖率与查询开销。不能直接把周期长度当作可自由插入的循环，不能把当前模板预测用作可行路径证书。

精确搜索用时14.9673秒，主要用途是离线结构提取，不适合作为在线估算器。当前快速基线未替换。
