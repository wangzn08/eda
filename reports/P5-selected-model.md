# P5 方案冻结：架构感知分层查表

## 选择依据

官方十亿请求的时间限制排除了逐条精确搜索。基于 Marquardt 等（FPGA 2000）的位移查表思想，本题候选结合有符号位移、起终端口偏置、官方 Gap/Block 特征、粗网格位置对，以及端口族×横纵方向残差表。所有拟合只使用固定开发集公开答案；验证集用于选择结构，不进入参数拟合。运行时不读取任何答案文件。

| 增量 | 验证集正延时评分 | 新增有效表项 | 决策 |
|---|---:|---:|---|
| 位移+端口偏置 | 85.17 | 2153 位移桶 | 基础 |
| 官方 Gap/Block 指示 | 86.89 | 26 | 采用 |
| 横/纵粗区域对 | 88.36 | 432+363 | 采用 |
| 端口族×方向 | **90.89** | 2342 | 采用 |
| 更高阶空间交互 | 最好约88.43（在88.36基线上） | 约7600 | 不采用，边际收益小 |
| 细端口或端口族×距离 | 最好约90.99（在90.89基线上） | 787至13220 | 暂不采用，边际收益≤0.10 |

压缩图精确求解保留为参考；短距离精确回退中位约0.68毫秒，无法作为十亿条流程的常规路径。ALT、CH 和 Hub Labeling 需要更高的预处理与状态空间验证，当前高速查表已满足本机时间和内存量级，因此不将其作为本轮提交路径。

## 冻结接口

选择 C++ `--algorithm port`。运行时参数保存在 `src/lookup_model.hpp`、`src/spatial_model.hpp`、`src/port_model.hpp`，架构 JSON 通过构建步骤内嵌。公开验证集 150053 条正延时评分 **90.88916720043925**，P50/P95/P99相对误差 **1.388% / 7.843% / 17.435%**；整数完全命中1041条。验证集无零延时行；零延时同点由程序直接输出0。

P6 解析与输出路径去掉逐行堆分配和无统计时的逐行计时后，优化前后验证输出 SHA-256 都是 `18d28897ded76b52d5b0ff32cdb9d2e312dad81c07ccd9cdfecc5087dbb3443a`。本机1000万条重复请求，优化后的端到端墙钟约 **1.97秒**、进程CPU约 **1.95秒**、峰值RSS约 **3.5MB**。此前空间模型、优化前解析路径的1000万条墙钟约3.29秒；两次模型和代码都不同，此数据只说明新方案的实测资源，不能当作纯解析优化的严格消融实验。

下一步在此版本上只做故障修复和提交包装，不再依据最终留出集调参。完成留出评估和五次十亿请求全流程后记录输出哈希、RSS、时间、编译环境及任何与官方平台的差异。
