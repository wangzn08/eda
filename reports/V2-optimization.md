# V2 准确率优化：源列、目标列与横向位移校正

基线为 `main` 分支已验收的端口族×方向模型。受 Marquardt 等（FPGA 2000）位移查表思想启发，V2 检查同一端口族在不同物理列的系统误差，并保持每条请求常数次查表。全部残差参数只从固定开发集拟合；下表是验证集结果，未使用最终留出集选方案。

| 逐层增加的特征 | 验证评分 | 有效新增表项 | 选择 |
|---|---:|---:|---|
| V1 端口族×方向 | 90.8892 | — | 参照 |
| 源列×端口族×方向 | 91.8706 | 11863 | 采用；源列宽1优于宽2–20 |
| 目标列×端口族×方向 | 92.3648 | 12192 | 采用 |
| 精确横向位移×纵向符号 | **92.5315** | 691 | 采用 |
| 起终列精确组合 | 92.5579（在上行基础上） | 14400 | 暂不采用；边际仅0.0264分 |

纵向分区、端口全名×列方向等特征分别试验后收益很小或参数代价较高，未纳入 V2。`--algorithm v2` 的完整150053条验证请求评分 **92.53153015795635**，P50/P95/P99相对误差 **1.078% / 6.464% / 15.340%**，与 Python 原型一致。相同本机的1000万条重复请求端到端墙钟约 **2.03秒**、峰值RSS约 **3.83MB**；V1对应约1.97秒、3.47MB，额外开销很小。

冻结后下一步：仅运行一次最终留出评估，随后切换默认入口，重新完成五次十亿请求、一致性和无数据目录编译验收。V1 `main` 分支与已交付源码包继续保留，直到 V2 全部验收通过。
