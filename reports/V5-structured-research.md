# V5 结构化路径模型研究（候选，未替换默认版）

## 为什么继续做

V4 的固定验证集总分为 93.4071，但 `|dy|<20` 的 10474 条仅得 80.554 分，P95 相对误差为 19.3%。说明短距离请求对端口、方向和局部结构更敏感。V4 仍是正式默认版本；本报告只使用开发集拟合，用验证集选择候选，再对选定的逐层版做一次留出核验。

研究依据是 [Martin 等人的 FPGA 延时预测特征](../papers/Martin_2021_ML_Delay_Prediction_author_copy.pdf)、[Marquardt 等人的位移延时表](../papers/Marquardt_2000_Timing_Driven_Placement.pdf)，以及已有 V3 的 Block/固定 Net 路径特征。V5 将位置、端口和相对位移的联合条件显式加入，而非仅继续增加单维表。

## 候选与结果

| 候选 | 验证集评分 | 留出集评分 | 千万条进程 CPU |
|---|---:|---:|---:|
| V4 默认版 | 93.4071 | 93.3964 | 交替测量约 2.28 秒 |
| 64 棵树，全部请求推理 | 93.6653 | 未评估 | 未部署；逐条树推理明显更慢 |
| V5 五层几何表，逐层取整 | 93.5155 | **93.5040** | 交替测量约 2.45 秒 |
| V5 五层几何表，合并取整 | **93.5160** | 未独立评估 | 交替测量约 **2.40 秒** |

五层几何表依次描述：源列×目标列、源端口×源列、源位置百格相位×横向距离、目标位置百格相位×横向距离、目标列×横向距离。参数只从开发集残差拟合，并对稀疏单元加 20 个先验样本。C++ 逐层版在验证集的 93.51549014095669 与 Python 完全一致。独立源码包能编译，逐层版验证输出与仓库版逐字节一致。

合并取整版保留同一组参数，只在五层求和后取整，验证分 93.51599925496323；因此它的留出分不能直接引用逐层版的 93.5040。实验扫描提示 Block 路径类别与纵向距离再组合可把合并版验证分提到约 93.543，但尚未固化或做留出核验。

## 选型结论

逐层版留出比 V4 高 0.1076 分；按准确性 80% 权重，贡献约 +0.086 分。千万条交替测量显示逐层版每千万条多约 0.185 秒，合并版多约 0.115 秒。若把这一差值线性外推到十亿条，时间项的扣分几乎抵消准确率收益。这个外推不能替代完整十亿条评测，且合并版尚未经过独立留出评估，因此当前不替换 V4 默认版。

接下来更有价值的复杂方案是对短距离与 Block 边界做**离线精确局部路径模板**：在官方图上离线求可复用的端口与几何模式距离，再把可覆盖的模板编译为常量表；无法匹配的请求回退到 V4。要先证明模板覆盖率、内存与查询成本，再考虑正式切换。把 64 棵树直接用于十亿次推理不划算。
